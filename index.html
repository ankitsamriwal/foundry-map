Models

Foundry Models

One catalog, one billing and capacity model. Over 11,000 models - frontier, open-weight, small, multimodal, industry-specific - all deployable behind the same endpoint shape.

Foundry Models catalog GA
The model floor
11,000+ models from OpenAI, Anthropic (Claude), Meta (Llama), Mistral, DeepSeek, xAI (Grok), Cohere, NVIDIA, Hugging Face and Microsoft's own Phi family. A leaderboard ranks by quality, cost and throughput.
Azure OpenAI in Foundry
Flagship GPT models, enterprise SLA
OpenAI's frontier models hosted inside Azure's security, compliance and regional boundary - the default starting point for most enterprise builds.
Model router Preview
Picks the model per request
Automatically routes each request to the best model for the latency and budget constraints you set. Microsoft reports up to 60% cost savings at similar accuracy versus pinning one flagship model.
Provisioned throughput
Reserved capacity, predictable bill
Buy reserved capacity across model families - including non-Microsoft models sold by Microsoft - so production agents get stable latency and a single billing experience.
Foundry Local
Models on the edge
Runs edge-optimized models and agents directly on Windows or macOS devices - for offline, latency-critical or privacy-sensitive workloads.
agents draw on the model floor
2

Agent Platform

Foundry Agent Service

The managed runtime where agents actually live: orchestration, memory, tools and protocols, without operating the plumbing yourself.

Foundry Agent Service GA
Managed agent runtime
GA since May 2025. Host a single agent or orchestrate a fleet. Brings built-in identity, persistent memory and observability; agent workloads run in Microsoft-managed containers with virtual-network isolation.
Microsoft Agent Framework Preview
The one SDK
The successor to Semantic Kernel and AutoGen, built by the same teams. One composable API for single agents, multi-agent graphs and human-in-the-loop workflows, in .NET and Python.
A2A + MCP protocols
Agents talk to agents and tools
Agent-to-Agent (A2A) exposes your agents to other agents; Model Context Protocol (MCP) connects them to 1,400+ MCP-enabled tools, plus OpenAPI and Logic Apps connectors.
Managed memory
Persistent context
Agents keep long-term context across sessions without you building the storage layer - scoped, secure and model-agnostic.
Voice Live API
Real-time speech agents
Real-time speech-in, speech-out in 150+ locales through one endpoint, so voice agents sit on the same stack as text agents.
agents ground themselves in knowledge
3

Knowledge

Foundry IQ

Agents are only as good as their context. This layer turns enterprise data into something an agent can actually reason over.

Foundry IQ Preview
The knowledge layer for agents
Announced November 2025, built on Azure AI Search. Reusable knowledge bases ground many agents through one API - no retrieval plumbing stitched into every project.
Agentic retrieval
Search that plans
A self-reflective query engine that plans, searches and synthesizes across sources, with configurable retrieval reasoning effort - the next generation of RAG.
Knowledge sources
Where the context lives
SharePoint, OneLake and Microsoft Fabric, Azure Blob Storage, Azure AI Search indexes and the web - indexed or federated, with document-level permissions respected.
Work IQ + Fabric IQ
The IQ family
Work IQ reads how your organization operates inside Microsoft 365; Fabric IQ adds business meaning to data. Foundry IQ unifies both into context every agent can draw on.

4

Production

Run, watch, publish

The difference between a demo and a deployment: evaluation, observability, cost control and a way into the tools people work in.

Evaluations + tracing
Prove it works
Built-in evaluation compares agent output against grading criteria - groundedness, task adherence, tool-call success - with full traces stored per project for debugging.
Foundry Control Plane
One dashboard for the fleet
Cross-project visibility into every agent, model and tool: run completion, compliance posture, cost and token usage, with bulk remediation across the fleet.
AI Red Teaming Agent
Attack yourself first
Automated vulnerability probing for jailbreaks and prompt injection (XPIA), with scheduled scans and drift monitoring before the internet does it for you.
Agent 365 GA
Registry and control, everywhere
GA November 2025. A control plane in the Microsoft 365 admin center for agents built anywhere - Microsoft, open-source or third-party: registry, access control, visualization, interoperability, security.
Publish to M365 + Teams
Meet users where they work
Agents built in Foundry publish directly into Microsoft 365 Copilot and Teams through the M365 Agents Toolkit - no separate distribution channel to build.
all of it under one trust boundary
5

Trust

Identity, data, security

Not a bolt-on layer - the same Microsoft security and governance systems that already run the enterprise, extended to agents.

Microsoft Entra
Identity for agents
Agents get first-class identities: RBAC, managed identity and conditional access apply to agents the way they apply to people and apps.
Microsoft Purview
Data governance + compliance
Extends data loss prevention, retention and compliance policies to generative AI and agents - including what agents may see and share.
Microsoft Defender
Threat protection for AI
Security signals for AI workloads and agents feed into the same Defender console the security team already watches.
Content Safety + RAI toolchain
Guardrails in the platform
Content filters, groundedness detection and responsible-AI tooling ship inside the platform rather than as homework, with network isolation and customer-managed keys underneath.
