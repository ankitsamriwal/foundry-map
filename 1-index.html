FIELD NOTES

The slide is already out of date

Ecosystem slides freeze a moving target. What has changed since this one was drawn tells you more than the logos do: the names churn, the floors stay.

R

Azure AI Foundry → Microsoft Foundry

The platform dropped "Azure" from its name; current documentation lives under Microsoft Foundry on Microsoft Learn. The pitch is now bigger than one cloud's branding.

R

Azure AI Search → Foundry IQ

The retrieval layer is being folded into the platform as Foundry IQ. RAG stops being a bolt-on and becomes a native capability.

G

Agent Service is generally available

GA since May 2025, with managed tools for Bing grounding, SharePoint, Logic Apps and code interpretation. Agents went from demo to supported workload.

G

The catalog passed 11,000 models

Per Microsoft's product page. The 18 model logos on the slide are the window display, not the warehouse.

R

Operations layer → Foundry Control Plane

Fleet-wide management, quotas and governance across agents now have a name of their own.
